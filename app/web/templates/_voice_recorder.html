{# ==================================================================== Voice recorder widget — WhatsApp-style multi-message voice input. Drops a self-contained record/stop/cancel/send control next to a chat text input. Multiple sequential recordings are supported by design — the JS resets MediaRecorder + stream after each recording. Required context: - ``lang`` (kk|ru|en) - widget injects itself into ``#voice-recorder-host`` (place this include after the chat-input markup with that anchor id). Optional context attributes the JS will read from the wrapper: - data-target-input="#chat-input" — receives transcribed text - data-target-send="#chat-send" — optional auto-click target - data-session-id="..." — preferred multi-turn endpoint - data-transcribe-url="/api/voice/transcribe" — override endpoint - data-autosend="0" — default: do not auto-send No raw audio is ever stored permanently. iOS / Safari devices get a ```` fallback. ==================================================================== #}
